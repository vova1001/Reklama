# 10. tech-lead: навигация в редакторе, черновики без потерь, только просмотры, обязательный срок

## Задача (менеджер, по словам заказчика)
1. В редакторе задания и анкеты левую навигацию не убирать — она остаётся как в приложении. Верхняя тонкая панель
   редактора (✕, «Правка / Как увидят», статус, «Осталось…», «Опубликовать») остаётся над колонкой контента.
2. Заполненные поля не теряются при обновлении страницы. Черновик формы сохраняется на сервере с паузой ~800 мс при
   каждом изменении: в Redis (ключ по пользователю и форме, срок 7 дней) через интерфейс DraftStore. Если REDIS_URL не
   задан или Redis недоступен — запасной вариант PostgreSQL. При открытии редактора восстанавливается последнее
   состояние (блоки, пункты, порядок, выбранные сферы, фото), индикатор «Сохранено · только что». Плюс мгновенная копия
   в localStorage на случай обрыва сети с последующей синхронизацией. Лимит размера черновика и частоты сохранений.
3. REDIS_URL — в render.yaml и .env.example (Render Key Value, тот же регион).
4. Лайки убрать везде: форма, проверка, API, БД (миграция), карточки ленты, страница задания, предпросмотр, главная.
   Условие выполнения — только просмотры.
5. Срок публикации обязателен: дата (время — по желанию), от завтра до 90 дней. Показывать в карточке и на странице
   задания («до 25 ноября»). Задания с прошедшим сроком в ленте не показывать; фоновая задача переводит их в
   «завершено». Проверка на фронте и на сервере.
- Тесты (-race), e2e: заполнить → обновить → поля на месте. Коммит, не пушить. Отчёт — 3 строки.

## Отчёт (техлид)
- **Сделано.**
  - Редактор открывается в оболочке приложения; липкая панель формы стоит над колонкой, её высота не меняется.
  - Черновик формы сохраняется сразу в localStorage, а через 800 мс — на сервер: `DraftStore`, Redis 7 дней или
    PostgreSQL как запас. Предел 64 КБ, частота ограничена; при открытии восстанавливается самое свежее, после отправки
    черновик удаляется.
  - Лайки убраны (миграция 00009). Срок публикации — дата и, по желанию, время по Москве, от завтра до 90 дней; он
    показан в карточке и на странице задания. Просроченные задания сразу пропадают из ленты, а раз в 5 минут
    переходят в статус «Завершено».
- **Проверено.** `make test` (-race, PostgreSQL и Redis) зелёный, покрытие 91,3%; `go vet`, gofmt и `astro check` без
  ошибок. e2e на 1440 / 768 / 375: 106 пройдено, 2 пропущены по замыслу; есть сценарии «заполнить → обновить → всё на
  месте» и «нет связи → копия на устройстве → синхронизация».
- **Попутно исправлено.**
  - Клик мышью мимо поля (например, по формату) иногда терялся: ошибка под только что покинутым полем сдвигала
    страницу. Теперь ошибка показывается после отпускания кнопки.
  - Пока черновик восстанавливается, форма на доли секунды недоступна для ввода, чтобы введённое не потерялось.
