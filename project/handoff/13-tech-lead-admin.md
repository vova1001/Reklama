# 13. tech-lead: админка — полная, боевая

## Задача (менеджер)
Полностью рабочая админка для проверки заданий бизнеса и анкет авторов. Прод-уровень: безопасность, аудит, удобство модератора.

**Доступ и безопасность**
- Роли: `admin` (всё + управление модераторами) и `moderator` (проверка, жалобы). Первые админы — из `ADMIN_EMAILS` (через запятую), назначаются при входе.
- Отдельный раздел `/admin` (тот же сайт, тот же вход), сервер проверяет роль на каждом запросе (middleware + service).
- 2FA для админов и модераторов: TOTP (Google Authenticator и т.п.) с резервными кодами; без 2FA доступ к /admin закрыт (кроме страницы настройки 2FA). Повторное подтверждение 2FA через 12 ч.
- Журнал действий (кто, что, когда, до/после, IP) — неизменяемый, с поиском. Лимиты, CSRF, no-store.

**Проверка (главное)**
- Очередь: задания и анкеты в статусе «на проверке» + правки опубликованных (новая версия ждёт, старая видна до одобрения) + свои категории/форматы + фото. Фильтры (тип, сфера, город, дата), поиск, сортировка «старые первыми», счётчик и время ожидания.
- Карточка проверки: как увидят пользователи + все поля, фото (просмотр поверх), подтверждённые соцсети, история автора/бизнеса (прошлые решения, жалобы).
- Решения: «Опубликовать», «Отклонить» (причина: шаблоны + свой текст), «Вернуть на доработку» (замечания по полям). Горячие клавиши (A/R/J/K), следующий в очереди автоматически, отмена решения 10 с.
- Блокировка конкурентной проверки: элемент берётся в работу модератором (аренда 10 мин), другой его не видит.
- Уведомление автору решения: почта + Telegram (если привязан), с причиной.
- Свои категории/форматы: одобрить в общие, объединить с существующей, отклонить.
- `MODERATION_MODE` переключается в админке (auto/manual) — хранится в БД, переменная окружения — значение по умолчанию.

**Остальное**
- Пользователи: поиск, карточка (профили, соцсети, задания/анкеты, входы), блокировка/разблокировка с причиной (блок = выход везде, скрытие из ленты), назначение модератора (только admin).
- Жалобы: кнопка «Пожаловаться» на задании/анкете/профиле (причины), очередь жалоб в админке, решения.
- Сводка: в очереди сейчас, решено за сегодня/неделю, среднее время проверки, новые пользователи — простые цифры.
- Дизайн: тот же минимализм приложения, плотнее (таблицы/списки), без лишнего.

- Go три слоя, интерфейсы, миграция, OpenAPI, тесты (-race, права доступа — обязательно: модератор не может admin-действий, обычный пользователь — ничего), e2e (вход админа с 2FA, одобрить/отклонить, жалоба, блокировка). Скриншоты не нужны. Коммит, не пушить. Отчёт 3 строки + дерево по слоям.
