# 09. tech-lead: полноэкранный редактор, удобная валидация, автопроверка, лента карточками

## Задача (менеджер, по словам заказчика)
1. **Баг:** заказчик не может отправить анкету автора. Найти причину (воспроизвести на живом сайте/в e2e), исправить, добавить тест.
2. **Валидация — удобнее:** ошибки у полей сразу после ухода с поля, при нажатии «Опубликовать» — прокрутка к первому незаполненному и подсветка;
   у кнопки — короткий список «Осталось: название, город…» (кликабельно, ведёт к полю). Ничего лишнего не требовать: обязательные — только действительно нужные.
   Серверная валидация остаётся, тексты ошибок те же, что на фронте.
3. **Проверка — пока автоматически:** `MODERATION_MODE=auto|manual` (по умолчанию сейчас `auto`): при отправке задание/анкета сразу публикуются (статус и журнал пишутся как «одобрено автоматически»). Переход на ручную — одной переменной. Добавить в render.yaml/.env.example.
4. **Редактор на весь экран:** создание/правка задания и анкеты — отдельный полноэкранный режим без левой навигации: сверху тонкая панель (✕ закрыть, «Правка / Как увидят», статус сохранения, «Опубликовать»), центр — удобная широкая колонка, ничего не налеплено.
5. **Списки и блоки удобнее:** у каждого блока нормальный **заголовок** (редактируется в строке), пункты: Enter — новый пункт, Backspace на пустом — удалить, вставка нескольких строк → несколько пунктов, перетаскивание за ручку, клавиатура (Alt+↑/↓). Шаблоны блоков одним нажатием («Что показать», «Требования», «Формат», «Сроки»).
6. **Лента — у всех и аккуратно:** опубликованные задания видят все пользователи (в режиме «Автор»), анкеты авторов — в режиме «Бизнес».
   - В ленте — сетка небольших аккуратных прямоугольных карточек: только фото и название (+ город/формат мелкой строкой допустимо).
   - **При наведении** фото плавно сменяется «полотном»: 3–4 коротких главных пункта (оплата, условия просмотров/лайков, формат, срок). На телефоне — по касанию/всегда кратко под фото.
   - **По нажатию** — страница задания/анкеты: полностью расписанный кейс (обложка, фото, все блоки, кнопка «Откликнуться»/«Предложить задание» — пока заглушка без сделок).
   - Пагинация (курсор), сортировка «новые», фильтр по сфере/городу/формату — компактно сверху.
- Go три слоя, интерфейсы, тесты (-race), e2e (бот анкеты исправлен, публикация автоматическая, лента видна другому пользователю, наведение/переход). Скриншоты не нужны. Коммит, не пушить. Отчёт коротко + дерево по слоям.

## Отчёт (техлид)
- **Баг анкеты** (воспроизведён локально в Playwright: вход по почте на живом сайте без кода из письма недоступен):
  пункт блока появлялся только по Enter — текст «О себе» без Enter не считался, а «О себе или примеры» было
  обязательным; площадки из профиля приходили без подписчиков; кнопка была недоступна, причина — только по наведению.
  Исправлено: пункты — сразу поля, блоки анкеты не обязательны, «Опубликовать» нажимается всегда и ведёт к полю;
  темы из профиля вне списка не подставляются. Тесты: сервис (анкета без блоков) и e2e «как у заказчика».
- **Сделано:** ошибки у поля после ухода с него, «Опубликовать» → прокрутка и подсветка первого, «Осталось: …»
  (слова ведут к полям), тексты ошибок = серверные; `MODERATION_MODE=auto|manual` (auto — сразу «Опубликовано»,
  в журнале «одобрено автоматически», атомарно); редактор на весь экран; блоки: заголовок в строке, Enter / Backspace /
  вставка строк / Alt+↑↓ / перетаскивание, шаблоны; лента у всех: авторам — задания, бизнесу — анкеты, сетка
  карточек 4:3, «полотно» при наведении (телефон — строка под фото), страница задания / автора, отбор, курсор.
- **Проверено:** `make test` (-race, PostgreSQL) — зелёные, покрытие 91,2%; gofmt, go vet; `astro check` — 0 ошибок;
  e2e (1440 / 768 / 375) — 103 пройдено, 2 пропущены по замыслу.
