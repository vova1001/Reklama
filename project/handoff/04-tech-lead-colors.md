# 04. tech-lead: цветовая гамма, отделение карточек, бесплатный тариф у авторов

## Задача (менеджер, по словам заказчика)
- «Белое на белом — такое себе», «сделай нормально цветовую гамму», «нет ничего про бесплатный тариф».
1. Светлая зона: лестница из 3 уровней — фон зоны ≈ #E9E7E1, карточки #FFFFFF с рамкой ≈ #DCD9D2 и мягкой тенью,
   вложенные панели ≈ #F3F1EC с рамкой; иконки — в изумрудном кружке-тинте, номера шагов контрастнее; новых цветов нет.
2. Тёмная зона: карточки и строки заметно светлее фона, разделители видимые.
3. «Возможности для авторов»: сначала «Бесплатно» (задания по теме и городу, оплата после проверки, 10 откликов в месяц),
   затем Про, затем Топ; метки: Бесплатно — нейтральная, Про — изумрудная, Топ — изумрудная заливка.
4. Контраст текста ≥ 4.5:1, скриншоты, e2e; коммит в ветку (пушит менеджер).

## Отчёт (техлид)
- Сделано: токены — фон #E9E7E1 → карточка #FFFFFF (рамка #DCD9D2 + мягкая тень) → панель #F3F1EC; серый текст
  затемнён до #605F5A (≥ 4.5:1 на фоне зоны); иконки и номера шагов — изумрудом на тинте; тёмные карточки #2B2B29,
  разделители видимее; у авторов 7 строк в карточке-списке: Бесплатно ×3 → Про ×2 → Топ ×2, три вида меток.
- Проверено: e2e 28 / 2 пропущено по замыслу; Lighthouse телефон 90/100/100/100, компьютер 100/100/100/100
  (контраст — без замечаний; свой обход всех видимых текстов — без нарушений); прокрутки вбок нет 320–1920;
  скриншоты `project/screens/home-*` просмотрены.
