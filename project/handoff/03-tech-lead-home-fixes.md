## Задача (менеджер, по словам заказчика)

   Пройти всю страницу глазами на всех ширинах и исправить всё неровное (наезды, обрезки, выравнивание).
2. **Меньше текста:** много текста повторяет себя. Оставить только самое нужное: у каждого блока — заголовок и максимум одна короткая строка;

4. **Шаги для авторов:** сейчас кружков 4, а шагов 3 — привести в соответствие. Лучше заменить на несколько простых шагов в один ряд (3 шага: Анкета → Задание → Оплата), без лишней графики.
