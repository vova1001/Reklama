# 01. tech-lead: каркас проекта и главная страница

## Задача
- Цель: начать настоящий сайт «Охват» (биржа рекламы у авторов видео). Сейчас — **только главная страница**, но каркас — на весь проект.
- Стек (как в студии): бэкенд на Go, трёхслойная архитектура (transport/http → service → repository), PostgreSQL, миграции;
  фронтенд Astro + Tailwind; всё в Docker, `docker compose up --build` поднимает всё одной командой. Makefile (dev, test, lint).
- Главная — пиксель в пиксель по макету: `project/design/desktop-01-home.png` (1440, 2x). Исходник макета (HTML/CSS, токены, шрифт Inter 4,
  фото, иконки Lucide) — `project/design/src/` и `project/design/README.md` (токены цветов, сетка, отступы). Фото — лицензии в `project/design/assets.md`;
  файлы фото — из `project/design/src` / ассетов макета (скопируй в `frontend/public/`).
- Адаптив: 375 / 768 / 1440 (мобильный — первым; мобильного макета нет — собери по системе макета аккуратно).
- Анимации (заказчик: «красивых анимаций, чтобы всё красиво»), сдержанно и дорого, как на apple.com / linear.app:
  появление блоков при прокрутке (fade + сдвиг 16–24px, по очереди у карточек), плавное появление заголовка первого экрана по словам,
  лёгкий параллакс/масштаб у фото первого экрана, наведение на карточки и кнопки (подъём, тень, стрелка сдвигается), шапка — стекло с размытием,
  при прокрутке уплотняется; вкладки/аккордеон FAQ с плавным раскрытием; знак «два круга» в финале — мягкое сближение кругов при появлении.
  Уважать `prefers-reduced-motion`. Без тяжёлых библиотек (CSS + IntersectionObserver; при необходимости Motion One). Lighthouse ≥ 90.
- Данные главной, которые меняются (категории, тарифы бизнеса и авторов, вопросы) — из API бэкенда (`GET /api/home` или отдельные),
  хранятся в БД с сидом; фронт рендерит при сборке/на сервере. Контракт — `backend/api/openapi.yaml`.
- Кнопки ведут на будущие страницы (`/tasks`, `/creators`, `/tasks/new`, `/creators/new`, `/pricing`, `/login`) — пока заглушка «Скоро».
- Тесты: модульные на сервис, интеграционный на repository (PostgreSQL в Docker), e2e Playwright: главная открывается, блоки на месте, нет ошибок в консоли.
  Скриншоты 375/768/1440 — в `project/screens/`.
- Сдать: код в репозитории, `README.md` (запуск), `architecture.md`, скриншоты. Коммиты понятные.
- Границы: только главная + каркас; без регистрации/оплат; ключей и паролей в файлах нет (`.env.example`).
- Готово, когда: `docker compose up --build` поднимает сайт на http://localhost:8000; главная совпадает с макетом; тесты зелёные; скриншоты сделаны.

## Отчёт (техлид)
- Сделано: каркас всего проекта и главная. Бэкенд Go 1.24 в три слоя (`httpapi` → `service` → `repository`/sqlc),
  PostgreSQL, миграции goose (схема + сид), контракт `backend/api/openapi.yaml`, `GET /api/home`, `/healthz`.
  Фронт — Astro 7 (SSR) + Tailwind 4: главная из API, адаптив 375 / 768 / 1024 / 1440, анимации на CSS + IntersectionObserver
  (заголовок по словам, появление блоков с очередью у карточек, параллакс и масштаб фото, наведение, стеклянная шапка
  уплотняется 80 → 64, плавный аккордеон, сближение кругов знака), `prefers-reduced-motion` учтён. Будущие страницы — «Скоро».
