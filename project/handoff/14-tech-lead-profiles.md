# 14. tech-lead: публичные профили бизнеса и автора (конструктор страницы)

## Задача (менеджер, по словам заказчика)
1. **Профиль бизнеса = страница-витрина** `/b/<slug>`: бизнес сам строит её из блоков (добавить / удалить / перетащить):
   «О компании» (текст), «Фото» (галерея), «Видео» (загрузка mp4 до N МБ или ссылка YouTube/VK — встраивание), «Адрес и контакты» (город, адрес, часы, сайт, соцсети), «Факты» (пункты), «Заголовок + текст».
   Шапка: логотип/аватар, название, сфера(ы), город, обложка. На странице — открытые задания этого бизнеса.
   Из карточки задания и страницы задания — ссылка на профиль бизнеса.
2. **У автора анкета и профиль — разные вещи:**
   - **Анкета** (уже есть) — коротко: какие услуги, форматы и цены. Остаётся в ленте бизнеса.
   - **Профиль** `/c/<slug>` — отдельно оформляемая страница из блоков: о себе, подтверждённые каналы (из задачи 12, автоматически), «Что могу рекламировать» (темы), примеры работ (фото/видео/ссылки), отзывы (заглушка до сделок), анкета(ы) автора.
   Из анкеты в ленте — ссылка на профиль.
3. Редактор профиля — тот же удобный конструктор блоков, что в задании (полноэкранный с левой навигацией, крупные поля, автосохранение черновика, «Как увидят»).
   Профиль проходит проверку (как задания/анкеты; в режиме auto — сразу), правки — новая версия на проверку, старая видна до одобрения. В админке — новый тип в очереди.
4. Видео: проверка типа и размера, без перекодирования (пока), хранение через тот же Storage, постер-кадр по возможности; встраивание YouTube/VK — только по белому списку доменов, безопасный iframe.
5. Slug: латиница/цифры/дефис, уникальный, по умолчанию из названия/имени, можно изменить, старый — редирект.
- Go три слоя, интерфейсы, миграция, OpenAPI, тесты (-race), e2e (бизнес собирает страницу с блоками и фото → публикуется → виден по ссылке; автор — профиль с каналами). Экономно: коммиты по частям, полный e2e один раз, без скриншотов. Не пушить. Отчёт 3 строки + дерево по слоям.
