# 02. tech-lead: главная v2 — логичная структура, больше о фичах, больше движения

## Задача (менеджер)
- Цель: переделать главную по замечаниям заказчика и выложить (Render обновится сам после пуша в ветку).
- Заказчик: «логическая графика: сначала кратко, зачем это нужно; потом для бизнеса — немного о нём; дальше для авторов — немного о них;
  там же побольше о фичах (кастомные штуки продвижения); больше движения; шапка графически сворачивается; продумай дизайн побольше».
- Стиль сохранить (Inter 4, тёмный верх, светлое полотно, мягкий контраст, изумруд-акцент, фото). Без мелкого шрифта (≥ 16–18px вне подвала).
- Новая логика страницы:
  1. **Первый экран** — как сейчас (заголовок по словам, 4 фото).
  2. **«Зачем это»** — одна крупная мысль + 3 тезиса с иконками: «Бизнес платит за результат, а не за обещания» · «Авторы берут заказы по своей теме» · «Сервис проверяет выполнение и переводит оплату». Можно анимированная схема: Бизнес → Задание → Автор → Проверка → Оплата (линия, которая «прорисовывается» при прокрутке).
  3. **Для бизнеса** (светлая зона): заголовок + 1–2 строки о ценности; 4 шага (как сейчас: тариф → задание → условия и счёт → автооплата);
     **фичи продвижения** крупными карточками: «Топ ленты» (задание первым в ленте N дней), «Своё оформление карточки» (обложка, цвет акцента, бейдж),
     «Расширенная статистика» (просмотры по городам, цена за 1000 просмотров, сравнение авторов), «Два вида заданий» (открытое / с одобрением),
     «Безопасная сделка» (деньги уходят автору автоматически после проверки), «Выгрузка отчётов». Для «Топ» и «Оформление» — живые мини-превью карточки задания (как выглядит выделенная карточка в ленте) — это главная визуальная «фишка».
     Затем тарифы бизнеса (0 / 3 000 / 10 000 ₽).
  4. **Для авторов** (тёмная зона): заголовок + 1–2 строки; как это работает для автора (3 шага: анкета → берёте задание → выполнили, загрузили ссылку → оплата);
     фичи: «Задания по вашей теме и городу», «Оплата сразу после проверки», «Свой профиль-оформление», «Место в топе каталога», «Значок Про», «Ранний доступ к новым заданиям»;
     мини-превью «выделенного профиля автора в каталоге»; тарифы авторов (0 / 3 000 / 10 000 ₽).
  5. Категории, вопросы, финальный призыв, подвал.
- Движение (сдержанно, но заметно; prefers-reduced-motion уважать):
  - **шапка сворачивается** при прокрутке: из полной ширины в компактную плавающую «пилюлю» по центру со стеклом (уменьшается высота, скругляются края, логотип становится знаком), обратно — при прокрутке вверх к началу;
  - прорисовка линии схемы «Зачем это», счёт/появление шагов по очереди, лёгкий параллакс фото, «живые» мини-превью (карточка в топе слегка поднимается/подсвечивается, бейдж появляется), sticky-заголовки зон «Для бизнеса»/«Для авторов» с переключением (можно индикатор прогресса);
  - плавные переходы между светлой и тёмной зонами.
- Тексты — короткие, по `project/business-model.md`; маркировку не обещать; комиссию не упоминать.
- Проверка: e2e зелёные, Lighthouse ≥ 90, скриншоты 375/768/1440 в `project/screens/` (v2), без горизонтального скролла.
- Сдать: коммиты в ветку (пушит менеджер), отчёт в этот файл.

## Отчёт (техлид)
- Сделано: главная перестроена по новой логике — первый экран → «Зачем это» (мысль подсвечивается по словам, схема
  Бизнес → Задание → Автор → Проверка → Оплата прорисовывается линией, 3 тезиса) → «Для бизнеса» (4 шага; инструменты
  продвижения: живые превью «Топ ленты» — выделенная карточка поднимается с 3-го места на 1-е, загорается обводка и
  бейдж; «Своё оформление» — обложка, бейдж, цвет акцента меняется сам или по нажатию; статистика, два вида заданий,
  безопасная сделка, выгрузка — с мини-примерами; тарифы) → «Для авторов» (тёмная зона: фото с параллаксом и
  уведомлением об оплате, шаги с линией, 6 возможностей, превью оформленного профиля в каталоге, тарифы) → темы,
  вопросы, призыв. Шапка сворачивается в стеклянную «пилюлю» по центру (уже, ниже, скруглена, название уходит, остаётся
  знак), у верха — разворачивается. Переключатель «Для бизнеса / Для авторов» с полоской прогресса плавает внизу по
  центру (сверху закрывал заголовки). Тёмные листы при входе расширяются до всей ширины. `prefers-reduced-motion` — всё
  сразу в итоговом виде. Блоки «Два вида заданий» и «С чего начать» убраны: их суть вошла в инструменты и зоны.
