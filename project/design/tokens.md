# Токены дизайна «Охват» — сайт, вход и приложение

Одна палитра на главную, вход и приложение. В коде — только эти токены (`frontend/src/styles/global.css`, блок `@theme`);
значений «на глаз» нет. Контраст текста — не ниже 4.5:1 (проверено формулой WCAG 2.1).

## Принцип
Спокойная тёплая гамма, без «белого на белом»: **лестница поверхностей** — фон → белая карточка с тонкой рамкой
и мягкой тенью → вложенная тёплая панель → «утопленное» (дорожки). Изумруд — фирменный **акцент**, а не заливка всего:
активный режим, прогресс, главное действие, «готово». Тёмный — главная кнопка и подсказки-номера.
Минимализм, крупная типографика Inter, пилюли (радиус 999px), карточки 24px.

## Форма и ритм
- **Шрифт:** Inter (файлом в проекте). Заголовок страницы приложения 30 → 38px (вес 680, трекинг −0.035em);
  заголовок карточки 20px / 650; текст 16px; подписи и метки — не меньше 14px.
- **Пилюли:** кнопки 48px (на главной 52px), поля 54px, поиск 44px; сегмент и вкладки — дорожка `sunken` 3px,
  выбранное — белая пилюля с тенью и изумрудной иконкой.
- **Кнопки:** `pill-dark` (главное действие формы), `pill-emerald` (главное действие экрана: «Создать задание»,
  «Заполнить»), `pill-ghost` (второстепенное: «Выйти»), `pill-danger` / `pill-danger-ol` (необратимое).
- **Радиусы:** карточка 24px, вложенная панель и иконка 14px, пункт меню 12px, всё интерактивное — пилюля.
- **Отступы:** поле экрана 12px (телефон) / 24px (≥768); между карточками 16–20px; внутри карточки 18–28px.
- **Тени:** только мягкие и короткие; меню и диалог — заметнее (`0 24px 48px -16px`).
- **Фокус:** обводка 2px `emerald`, отступ 2px; в меню — заливка `panel` + внутренняя обводка.
- **Нажатие:** область не меньше 44×44px (нижняя навигация 58px).

## Раскладка приложения
- **Шапка** (белое стекло, линия снизу): знак → лента, сегмент «Бизнес / Автор», поиск (≥768), аватар → меню
  (Профиль, Режим, Настройки входа, Выйти).
- **Центр** — лента / профиль / настройки; **справа** (≥1024, 340px) — прогресс профиля, быстрые действия,
  подсказка, тариф, «как это работает».
- **Телефон** (<768): нижняя навигация (Лента, Поиск, Профиль, Настройки), колонка «полезное» — под содержимым.

## Где согласовано
- Главная: те же `bg / card / panel / line / ink / gray / emerald`; тёмная зона — `dark / dark-card`.
- Вход: карточка `card` на `bg`, поля `panel`, ошибки `error`, подсказка в поле `placeholder`.
- Приложение: всё выше плюс `sunken`, `line-strong`, `emerald-*`, `warn-*`.
