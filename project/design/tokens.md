# Токены дизайна «Охват» — сайт, вход и приложение

Одна палитра на главную, вход и приложение. В коде — только эти токены (`frontend/src/styles/global.css`, блок `@theme`);
значений «на глаз» нет. Контраст текста — не ниже 4.5:1 (формула WCAG 2.1; e2e проверяет все тексты приложения).

## Принцип
Почти монохром: белый, три серых, графит — и **один** акцент, изумруд. Изумруд — только то, на что нажать или что
«хорошо»: главное действие, активный режим, «опубликовано». Ошибка и «отклонено» — красный (это состояние, не акцент).
В приложении минимум поверхностей: белый фон + содержимое, разделители — линии 1px; без карточек, теней и
«карточек в карточках». Тень — только у всплывающего (меню, диалог, сообщение).

## Форма и ритм
- **Шрифт:** Inter (файлом в проекте). Заголовок страницы 26 → 30px / 680; заголовок задания 18px / 620; текст 16px;
  подписи и метки — 14–15px.
- **Сетка 4/8:** строка навигации и меню — 48 / 44px; поле — 48px; иконки 20–24px, линия 1.5, на одной оси с текстом.
- **Радиусы:** поля и пункты 12px, фото 12–14px, пилюли и кнопки — 999px.
- **Активный пункт:** заливка `panel` + полужирный, без рамок и бейджей. Выбранная пилюля (формат, сфера) — графит.
- **Статус:** точка 7px + слово (`черновик` серый, `на проверке` графит, `опубликовано` изумруд, `отклонено` красный).
- **Кнопки:** `pill-emerald` (главное действие экрана: «Создать», «На проверку»), `pill-dark` (сохранить), `pill-ghost`
  (второстепенное), `pill-text` (действие в строке), `pill-danger-ol` (необратимое). Недоступная — `aria-disabled`,
  причина — своей подсказкой по наведению и фокусу.
- **Фокус:** обводка 2px `emerald`, отступ 2px. **Нажатие:** не меньше 44×44px.
- **Движение:** 120–220 мс, только появление и сворачивание; при «уменьшить движение» — без анимаций.

## Раскладка приложения
- **Слева — всё служебное** (≥768): знак, навигация (Лента, Создать, Мои — у бизнеса; Анкета — у автора; Профиль,
  Настройки), переключатель «Бизнес / Автор», внизу — аватар с меню (Профиль, Настройки, Выйти).
  768–1199 — колонка 76px, только иконки (подпись — подсказкой); ≥1200 — 248px с подписями.
- **Справа — одна колонка** содержимого до 600px. Правой колонки нет. Напоминание заполнить профиль — одна тонкая
  строка вверху ленты, закрывается. Тариф — только в настройках.
- **Телефон** (<768): сверху знак, режим, аватар; снизу — навигация (иконка + подпись, 56px).

## Редактор и лента (задача 09)
- **Редактор:** навигация приложения остаётся (задача 10). Над колонкой — тонкая липкая панель на белом с размытием
  (60px; телефон — 2 строки, под шапкой): ✕, «Правка / Как увидят» (дорожка `sunken`), «Сохранено · только что» `gray`
  14px, «Осталось: …» (одна строка, `gray`, слова — `ink` с подчёркиванием `line-strong`), «Опубликовать»
  (`pill-emerald`, всегда доступна). Высота панели не меняется. Колонка — до 760px; название — крупно в строке (28 → 34px / 680), без заливки поля.
- **Ошибка поля:** текст `error` 14px под полем, рамка поля 2px `error`; подсветка при переходе — заливка
  `error` 8% и тень 8px, гаснет за 1,6 с.
- **Блоки:** заголовок в строке (17px / 650), пункты — поля без рамки, при фокусе — `panel`; шаблоны — пилюли `chip sm`.
- **Лента:** сетка 2 колонки (телефон) / 3 (≥768), до 1040px; карточка — фото 4:3, радиус 14px, название 16px / 600
  (2 строки), строка `gray` 14px. «Полотно» при наведении — графит 82%, белый текст 14px, появление 280 мс, фото
  слегка увеличивается и размывается. На телефоне — главное строкой `ink` под фото. Отбор — пилюли 38px
  (выбрано — графит), список — свой (как меню).
- **Страница задания и анкеты:** обложка 16:9, радиус 16px; условия — строки 48px через линию; действие — внизу липкой
  строкой (`pill-emerald`).

## Формы, мультивыбор, просмотр фото (задача 11)
- **Разделы формы:** линия `line` сверху, заголовок 21px / 680, под ним подсказка одной строкой 15px `gray` (6.0:1);
  задание — «Основное / Условия / Описание / Фото», анкета — «Основное / Площадки / О себе / Работы», профиль — «Общие
  данные / Режимы». Между полями — 18px, раздел — 28px сверху.
- **Поля:** подпись 17px / 600, пояснение в подписи 15px `gray`; поле 54px, текст 17px, радиус 12px; пилюли 44px / 16px;
  ошибка 15px `error`.
- **Мультивыбор:** выбранная пилюля — графит с белой галочкой слева (появляется за 160 мс); «+ Своя / + Свой» —
  контурная пилюля, открывает поле с подсказками. Список отбора ленты — несколько отметок (точка `emerald`).
- **Срок:** пилюли «3 дня / Неделя / 2 недели / Месяц / + Свой»; «Свой» — панель с рамкой `line`, радиус 14px:
  календарь (день 44px, выбранный — графит, сегодня — полужирный, вне диапазона — `line-strong`), время 54px,
  итог строкой 16px / 600.
- **Просмотр фото:** поверх страницы фон `#0C0C0C` 94%, счётчик «3 / 9» 16px / 600 `on-dark`, кнопки 48px (белые иконки,
  наведение — белый 12%), миниатюры 56px (телефон — 48px), текущая — белая рамка 2px, остальные — 50%; переход —
  сдвиг 40px + проявление 220 мс, открытие и закрытие — проявление 200 / 160 мс; при «уменьшить движение» — без анимаций.

## Где согласовано
- Главная: `bg / card / line / ink / gray / emerald`; тёмные зоны — `dark / dark-card / on-dark / gray-dark`.
- Вход: белая карточка на `bg`, поля `panel`, ошибки `error`, подсказка `placeholder`.
- Приложение: белый фон, линии `line`, поля `panel`, дорожки `sunken`, акцент `emerald`.
